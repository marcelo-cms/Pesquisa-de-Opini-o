# 📊 Pesquisa de Opinião do Cliente

Autor: Carlos Marcelo Silva

Um script simples em **Python** desenvolvido para treinar o conceito de estruturas de repetição.


## 📊 Funcionalidades

* **Coleta de Dados:** Registra nome e idade de cada participante.
* **Opinião:** Permite escolher entre três opções de notas:
  * `1` - Excelente
  * `2` - Bom
  * `3` - Ruim

* **Relatório Final:** Exibe a contagem total de votos para cada categoria após o término das 10 entrevistas.

## 🛠️ Tecnologias Utilizadas

* **Python 3** (Lógica de programação, estruturas de repetição e condicionais)
